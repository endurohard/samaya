# samaya · Аудит под DIKIDI + правки (модалки и аналитика, desktop + mobile)

Дата: 2026-06-26. Объём проверки: `services/frontend/src` — модалки (booking, клиент, финансы, услуги, схемы ЗП), карточки аналитики (donut-графики журнала) и финансовые KPI-карточки; десктоп и мобильные (iPhone 375–430, Android 360–412).

В архиве — **только изменённые файлы**: `style.css` и `index.html`. `app.js` править не понадобилось (главный функциональный баг закрыт на уровне CSS, без риска для логики).

## TL;DR

Продукт уже близок к DIKIDI и хорошо проработан адаптивно (фуллскрин-модалки ≤900px, safe-area, off-canvas сайдбар, focus-trap, единые токены). Найдены и исправлены: **1 реальный функциональный баг** (атрибут `hidden` не скрывал блоки журнала), **рассинхрон заголовков модалок**, **off-brand цвета финансовых донатов** и **перенос суммы в KPI-карточках**. Все правки безопасные и проверены визуально.

## Что исправлено

### 1. ❗ Баг: `hidden` не скрывал график/список/аналитику в журнале — `style.css`
`applyJournalMode()` переключает режим через `el.hidden = true/false` для `#journalCalendar`, `#journalList`, `#journalCharts`, `#journalFiltersPanel`. Но author-правила `.journal-charts { display:grid }` и `.data-list { display:flex }` **перебивают** UA-стиль `[hidden]{display:none}` (одинаковая специфичность → побеждает author). В результате в режиме «Календарь» список и donut-аналитика **оставались видимыми**.
Проверено эмпирически: `.data-list[hidden]` → `display:flex`, `.journal-charts[hidden]` → `display:grid`.
**Фикс:** добавлено базовое правило `[hidden] { display:none !important; }` — чинит весь класс таких багов разом (любой блок, скрываемый через атрибут).

### 2. Рассинхрон размера заголовка модалок — `style.css`
Booking / финансы / импорт используют `<h3>` → `.modal-head h3` = `--fs-xl` (18px). Услуги / зарплата / продажа используют `.modal-title` = `--fs-2xl` (22px, 700). Заголовки «прыгали» между семействами модалок.
**Фикс:** `.modal-title` сведён к `--fs-xl`; `.modal-head h3` получил `font-weight:700` + `letter-spacing` + цвет токеном. Теперь все модалки имеют единый заголовок 18/700.

### 3. Статус-точка вплотную к заголовку (booking) — `style.css`
`.modal-head` (flex) не имел `gap`, точка статуса прилипала к тексту даты.
**Фикс:** `.modal-head { gap: 8px }`.

### 4. Off-brand цвета финансовых KPI — `index.html` + `style.css`
- Донат «Остаток на начало» был произвольно-синим `#3b82f6`, «на конец» — `#16a34a`. → переведены на бренд-токены `var(--primary)` и `var(--success)`.
- `.fin-kpi-income/.fin-kpi-expense` использовали хардкод `#16a34a` / `#dc2626` → токены `var(--success)` / `var(--danger-hover)`.
JS красит только заполнение (`stroke-dasharray`), цвет статичен — правка безопасна.

### 5. Перенос суммы в KPI-карточках (читаемость) — `style.css`
На карточках с донатом сумма «128 400 ₽» **переносилась на 2 строки** уже на десктопе и тем более на мобиле.
**Фикс:** `.fin-kpi-val { white-space:nowrap }`, донат уменьшен до 64×64, на balance-картах сумма = `--fs-xl`. Теперь сумма в одну строку рядом с донатом.

### 6. Мобильный фуллскрин-модал: `100vw` → `100%` — `style.css`
`width:100vw` включает ширину скроллбара и может давать горизонтальный овелфлоу; `position:fixed; left:0; right:0` уже задаёт ширину. Заменено на `100%`.

## Что уже хорошо (не трогали)

- Адаптив модалок: фуллскрин ≤900px, sticky head/foot, скролл только в body, `env(safe-area-inset-*)`, защита от iOS-зума (`font-size:16px`).
- Donut-аналитика: 4→2→1 колонки, увеличенный донат на мобиле, аккуратная легенда с tabular-nums.
- Доступность: `trapFocus`, закрытие по ESC и клику на backdrop, единый `:focus-visible`.
- Мульти-цветные палитры графиков (по типу карточки) — намеренно, в духе DIKIDI; оставлены.

## Рекомендации на следующий проход (не входило в правки)

1. **Консолидировать 3 перекрывающихся `@media (max-width:900px)` блока** для фуллскрин-модалок (`~3624`, `~3848`, `~3878`) в один — сейчас работает, но это дрейф.
2. Перевести оставшийся хардкод-цвет (финанс-донат `#22c5d8` и пр.) на токены, если нужна централизованная смена темы.
3. Контраст `--text-muted` (#9aa3b2) на мелком тексте — проверить на WCAG AA.
4. Тёмная тема через переопределение `:root` (дёшево после токенов).
